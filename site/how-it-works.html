How the switcher behaves

The full description of the overlay and its gestures. The home page has the short version. Per-workspace configuration lives in settings, and the hardware checklist verifies this behavior release by release.

The keyboard gesture

Hold Alt and tap Tab: an overlay lists the windows of the current workspace in most-recently-used order. Tab walks forward, Shift+Tab back, and the arrow keys step too: Up or Left back, Down or Right forward. Releasing Alt focuses the selection and dismisses the overlay; Enter confirms the same outcome without letting go of Alt. Escape dismisses without switching. A quick tap, released before the overlay appears, still switches. Ctrl+1 through Ctrl+9, keypad digits included, switch to that row's window at once, like a click; the first nine rows show their key at the right edge, deeper rows show none, and the number row does nothing without Ctrl.

The pointer gesture

The mouse drives the same gesture while the overlay is up. Crossing between rows, or between tiles on the horizontal card, moves the selection; wherever the pointer first lands, including right where the card appears, claims nothing. Clicking a row focuses that window and dismisses the overlay, like releasing Alt. On the column card, resting the pointer on a window row reveals an × at its right edge; clicking it closes the window instead (see Closing windows). The scroll wheel steps the list one row per notch, forward or back, wrapping like Tab, and a slow scan never times the overlay out.

The frozen list

The list is frozen for the gesture: a window that opened after the overlay appeared is not on it, so neither the pointer, the wheel, nor a number key can reach it mid-gesture.

Grouped mode

The grouping = true setting re-partitions the same list into a two-level tree: one entry per application, ordered by each app's most recently used window, with that app's whole window set nested beneath it, plus a top-level row for each window COSMIC cannot attribute to any app and for each single-window app. Groups start collapsed; expanding one (→) is remembered for as long as the daemon runs. Committing an entry activates that app's most recently used window, the same window its first child shows.

The keys re-bind to the tree, one walk: Tab, ↑/↓, and the wheel step one visible row at a time, wrapping, through entries, leaves, and the windows of expanded groups. A collapsed group contributes only its entry, and nothing descends into one. → expands and enters, landing one past the window you just left when it is your own app; ← on a child returns to its entry (the group stays expanded), and on an expanded entry collapses it. Ctrl+N activates the Nth app entry's window. The pointer picks rows like the keyboard does, expanded entries included. The frozen-list rule holds: the window set never changes mid-gesture, only which of it stands expanded. The full table, including how a quick tap lands, is in settings.

Type-to-filter

While the card is up, typing filters it. Printable keys type straight through the held Alt: the query collects in a strip above the rows, and each keystroke narrows the card to the windows whose title or application name contains it (case-insensitive), with the selection on the first match. Tab, the arrows, and the wheel step the matches; Enter or releasing Alt switches to the selected one. It works in every mode: the flat list, the grouped tree (which flattens to its matching windows while a query stands), and the same-app view, each narrowing the list the gesture froze. Ctrl+N keeps its chord; every other printable key, digits included, types.

Backspace erases the last character and does nothing on an empty query. Escape clears a standing query first; only an empty query dismisses. Clearing restores the card you had, keeping the window you had selected when it is still there. When nothing matches, the card keeps the query with a one-word verdict and commits as a no-op. The query dies with the gesture: nothing persists, and the window list never re-derives mid-gesture.

Closing windows

Windows close from the card without leaving the gesture. Alt+minus (top-row or keypad) closes the selected row's window; on the pointer's side, resting on a window row reveals an × at its right edge, in the strip where that row's key hint sits, and clicking it closes that row's window instead of activating it. Every row closes exactly what it activates: a group entry closes its app's most recently used window, the same window the entry commits, and a query row closes the window it shows.

After each close the selection moves to the next visible row, wrapping when it rested there, and the card stays up, so one held gesture can prune a stack of windows: Alt+minus, Alt+minus, then Tab to what survives. Closing the last eligible window dismisses the overlay. The × is the column card's affordance, on window rows only, never on group entries or the … rows; Alt+minus works in every mode: the flat list, the grouped tree, a standing query, and the same-app view. A window closed by someone else mid-gesture drops off the same way; closing never adds one back.

The card

Each row shows the window's application icon, resolved through the same desktop-entry and icon-theme pipeline the COSMIC launcher uses, next to its title; an application with no themed icon falls back to a generic window glyph. The card is a rounded rectangle with a hairline border, at most 748 px wide, with the selected row highlighted; text renders at 12 px and stays sharp on HiDPI displays (the overlay renders at the output's scale). theme picks the card; auto (the default) follows the desktop's dark/light preference; see settings.

layout = "horizontal" trades the column for a wide, short band: the same windows as tiles, each the app icon with the title beneath and clamped to the tile, ended by a … tile when the list outgrows the band. Left and Right step the band, Ctrl+N and the pointer address its tiles as they address rows, and columns sizes it: two-thirds of the invoking output ("auto", the default) or a pinned 3–12 tiles. See settings.

Workspace scoping

Only windows whose workspace set includes the current workspace are listed: sticky windows appear everywhere, minimized windows nowhere, and a window parked on another workspace can never be focused through Airlock. A workspace can opt into the global list through the config file; see settings.

The extra keys

airlock install also claims three more keys. Hold Alt and tap ` (the key above Tab): the overlay lists only the current application's windows, most recently used first. The gesture and the isolation rule match Alt+Tab (isolated = false widens the list to that application's windows everywhere). Alt+Shift+` opens it stepping backwards. An application with fewer than two windows in scope does nothing. Alt+Esc switches to the second-most-recent window under the same scope, the window a quick Alt+Tab tap would reach, with no overlay.

The daemon

A small daemon keeps a live snapshot of the compositor state; the keybind stubs are milliseconds-thin and auto-start it on first press. The overlay is software-rendered; no GPU required.
