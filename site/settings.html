Settings

By default, Airlock limits Alt+Tab to the current workspace. A config file can opt individual workspaces out: there the switcher lists every non-minimized window across all workspaces, most-recently-used first, while workspaces without an entry stay isolated. The same file picks the card color (light, dark, or following the desktop) and how many windows the card keeps in view.

Airlock reads the file; you write it. Airlock never creates, renames, or rearranges workspaces; names and positions come from COSMIC itself.

The config file

~/.config/airlock/config.toml

More precisely: airlock/config.toml under an absolute $XDG_CONFIG_HOME when one is set, else under $HOME/.config, the same rule the installer uses. No file, or an empty one, means every workspace isolated.

A full config file

# ~/.config/airlock/config.toml: Airlock reads, you edit.
# Workspaces without an entry keep the default: isolated.

theme = "auto"         # match the desktop's dark/light mode (the default)
# font = "Fira Sans"   # absent (the default): the COSMIC interface font
# font_size = 12       # card text size, logical px: 8–24 (the default: 12)
rows = 8               # windows the card keeps in view (the default)
layout = "vertical"    # the tall card; "horizontal" lays it out as tiles
# columns = "auto"     # the band's tile budget; or a whole number 3–12
# width = "auto"       # the card's width floor; "100%" fills the screen, or a pixel count
# min-width = "auto"   # the card's never-below width; same values as width
grouping = false       # the flat list (the default); true groups it by app

[[workspace]]
name = "code"          # matches a workspace COSMIC reports as named "code"
isolated = true        # the default; shown for completeness

[[workspace]]
index = 2              # the 2nd workspace in COSMIC's order, named or not
isolated = false       # Alt+Tab here cycles all windows, MRU

Workspace keys

Each [[workspace]] entry takes exactly one reference plus an optional flag:

KeyTypeMeaning
namestringMatches a workspace COSMIC reports with exactly this name
indexwhole number ≥ 1Matches the workspace at this 1-based position
isolatedbooleantrue (default): only this workspace's windows; false: all windows, MRU

An entry needs name or index, never both.

The top-level keys: theme picks the card (see Theme); rows how many windows it keeps in view (see Rows); font the typeface (see Font); layout the card's axis and columns the band's tile budget (see Layout and Columns); grouping the list's shape (see Grouping).

Referencing workspaces

  • Name-first. A named workspace matches name rules before index rules. index is the fallback, and covers unnamed workspaces.
  • A name rule follows the name, not the workspace. Names are read live on every press: rename code to dev in COSMIC and the rule stops matching that workspace on the next invocation, and matches whichever workspace later takes the name code.
  • Positions shift with the grid. index is the workspace's 1-based place in COSMIC's order (sorted by grid coordinates). Creating, removing, or moving workspaces re-points an index rule at whatever now sits there. Prefer name for workspaces you have named.
  • Out-of-range index matches nothing: that workspace falls back to the isolated default.
  • Duplicates are allowed; the last entry in file order wins. No error.
  • No match at all: the workspace stays isolated. An entry can only opt out, never opt others in.

Theme

theme picks the card the switcher paints: the near-opaque panel the window list sits on. Three values:

  • "auto" (default): follow the COSMIC system dark/light preference. A dark-mode desktop paints the dark card, a light-mode desktop the light one. The preference is read when a gesture starts, so flipping dark mode, in COSMIC Settings or on a schedule, shows up on the next Alt+Tab. No daemon restart.
  • "dark": always the dark card, whatever the desktop prefers.
  • "light": always the light card.

Theme can never break switching. An unreadable system preference paints the dark card and logs one diagnostic; a malformed theme value falls back to the last-good settings like any other config error.

Rows

rows sets how many windows the card keeps in view on a long list (a whole number from 3 to 10, default 8). The … continuation rows at truncated edges ride on top of that budget, never inside it: with the default, a long list shows eight windows mid-list, nine at either end, and a list of ten or fewer shows every window with no … at all.

The card grows by two rows once the list outgrows rows (the … slots). At the default text size that is 584 logical pixels tall, which fits any 100%-scaled display and a 1440p screen at 200%. A 1080p panel at 200% (a 540-logical screen) is the exception: rows = 7 keeps the card inside that height. A larger font_size grows each row, so fewer windows fit and the budget clamps (see What follows the desktop).

A value outside 3–10, or a non-integer, is named in a diagnostic and the last-good settings apply.

Font

font picks the typeface the card's titles paint in: a font family name, exactly as your font picker shows it. Weight stays Regular, and size stays the card's own 12 px unless font_size moves it.

  • Absent key (the default): follow the COSMIC interface font, the family your desktop already paints its UI in. Open Sans on a default desktop, your own COSMIC Settings pick when you have made one.
  • font = "Fira Sans": any installed family; the next Alt+Tab paints it.

Any string is valid; a family nothing installs is not a config error. Resolution happens when a gesture starts: an unknown name logs one diagnostic naming the font key and paints the interface font instead. A system with no loadable fonts at all paints the built-in bitmap face; switching never breaks on font I/O.

Unicode titles render their actual glyphs through the font's fallback chains, with grayscale anti-aliasing and proportional widths. Fonts are scanned once at daemon startup, so a font installed while the daemon runs is picked up at the next daemon restart.

Font size

font_size sets the card's text size in logical pixels: a whole number from 8 to 24, default 12. It sizes every piece of text the card paints: titles, the query strip, the Ctrl+N digits, and the horizontal band's caption and tile badges. The 8×8 bitmap floor scales with it too, so a system with no loadable fonts still obeys the setting.

The geometry that depends on text follows. A taller line grows each row and the query strip, and the horizontal band's caption row; the band card's height grows with its caption. The title band keeps its roughly 600-px physical budget by fitting fewer characters rather than stretching: a 24-px card shows about half the columns of a 12-px one, and a long title elides sooner. Icons, paddings, gaps, and weight stay fixed: this is a text-size knob, not a UI zoom. Because the rows grow, a larger size fits fewer windows in the 720-px panel and the rows budget clamps exactly as it does at Spacious density.

font_size is read when a gesture starts and frozen for the session, like font: an edit applies on the next press, never to the open card. A value outside 8–24, or a non-integer, is named in a diagnostic and the last-good settings apply.

What follows the desktop

Three card values follow the COSMIC desktop. Corner radius and row rhythm have no keys because the desktop owns the choice. The typeface is the default of font, so it follows until you override it.

  • Corner radius follows Appearance → Style. Round, Slightly-Round, and Square round the card's corners at 12, 8, and 2 logical pixels; the selection band rounds with the card, never past 8.
  • Row rhythm follows Appearance → Interface density. Compact, Comfortable, and Spacious set the rows' height, gap, and the card's vertical padding. Rows stay icon-driven, 40/48/56 px tall by density. The card's width never changes with density.
  • The typeface follows the desktop's interface font (the font key's default; see Font): the family COSMIC Settings' own font picker writes, family-only, at the default 12 px (font_size moves the size). An unreadable store keeps Open Sans and logs one diagnostic.

The two geometry values are read when a gesture starts, like every setting. An unreadable or missing COSMIC store keeps the factory-default geometry and logs one diagnostic.

The rows clamp: every card must fit a 720-logical-pixel panel. At Spacious the tallest card the rows ceiling could build would not, so the budget clamps to what fits: rows = 9 or 10 at Spacious opens with eight windows in view and one diagnostic naming the density, the text size, the setting, and the clamp. The setting keeps its value: back at Comfortable the full budget returns. A larger font_size grows the rows and can bind the same clamp at any density; at 24 px even Spacious's default eight clamps to six.

Layout

layout picks the card's axis. Two values:

  • "vertical" (default): the tall column of rows.
  • "horizontal": the band, the same MRU window list as one row of tiles in a wide, short card. A tile is the window's application icon with its title beneath, clamped to the tile's width; a list longer than the band ends in a … tile, and stepping past the band scrolls it enough to keep the selection visible. Left and Right become the primary step keys (Up and Down still step, as aliases), and Ctrl+1..9 addresses tiles in reading order, the chord shown as a corner badge on the first nine. The pointer drives the same gesture per tile: hover moves the selection, a click commits, the wheel steps.

rows binds the vertical card only; the band's budget is Columns. A grouped session (grouping = true) renders the grouped card, which is vertical; layout binds the flat list.

Columns

columns sizes the horizontal band: "auto" (the default) or a whole number from 3 to 12. The vertical card ignores it.

  • "auto": the strip holds as many tiles as two-thirds of the invoking output's logical width fits, never fewer than three. A 1920-logical output opens seventeen tiles, a 2560 one twenty-three. The share is read from the output the gesture starts on and frozen for the session, so auto is per monitor, not mid-gesture.
  • A whole number: a pinned budget of exactly that many tiles, whatever the output. Three is the shortest strip that still reads as one; twelve spans 904 logical pixels.

Whatever the budget, the card keeps a caption-width floor: a short strip renders left-aligned inside a card wide enough that the caption always reads, so the card never narrows below it.

columns is read with layout when a gesture starts and frozen for the session; a pinned value applies on the next press.

Width

width and min-width set a floor under the card's width, with the same values and the same meaning on both the vertical card and the horizontal band:

  • "auto" (the default): the card sizes from its content, the widest title row on the vertical card, the tile shape on the band. An unset key is "auto".
  • "100%": the whole invoking output's logical width. A percentage from "1%" to "100%" is a share of that width.
  • A whole number: that many logical pixels.

The card grows to the larger of the two keys and its content: a value below what the card needs changes nothing, so a title never clips. A pixel count past the invoking output clamps back to the output, keeping the card whole on the screen, and the daemon log names the clamp.

On the horizontal band, columns still counts tiles: a widened card keeps its tiles left-aligned with air on the right, exactly as the caption floor already does for a short strip.

Both keys are read when a gesture starts and frozen for the session like columns; an edit applies on the next press.

Grouping

grouping = true re-partitions the same MRU window list into a two-level tree. Level 1 is the app layer: one entry per application, ordered by each app's most-recently-used window, plus one row per window COSMIC cannot attribute to any app. An entry is a label, never a window itself, but committing it (Alt release or Enter) activates its app's most recently used window, the same window its first child shows.

Groups start collapsed: the card opens showing only the level-1 entries. Expanding is part of entering (→ below), and the expanded or collapsed state of every app persists across gestures for as long as the daemon runs.

The keys re-bind to the tree:

  • Alt+Tab / Alt+Shift+Tab, ↑/↓, and the mouse wheel are one and the same walk: one visible row at a time, wrapping, through entries, leaves, and the windows of expanded groups. A collapsed group contributes only its entry; nothing descends into a collapsed group, and a workspace holding a single collapsed entry keeps the selection where it is.
  • → expands the selected group (the state persists) and enters its windows, landing on the most recently used one, or one past the window you just left when entering your own app. On a leaf it does nothing.
  • ← on a child returns to its entry (the group stays expanded); on an expanded entry it collapses the group; elsewhere it does nothing.
  • Ctrl+1..9 activates the Nth level-1 entry's window instantly.
  • ` (the key above Tab) works the selected app's group in either grouped card — the vertical tree and the horizontal strip alike. On an app entry or tile it toggles the group: a collapsed entry opens that app's windows on their most recently used one (Shift+` on the last); an expanded entry collapses in place. From a window row or tile it cycles the same app's windows, wrapping within the app. A querying session is flat, so there the key types into the query.
  • Flat mode (grouping = false, the default) is unchanged: Tab steps rows and ←/→ ride with ↑/↓ as step aliases.

The quick tap, one Tab press with Alt released before the card can be read, is the first step of the same walk: your own app's next window when its group is expanded (the flat list's MRU-second window), the next app entry's window while it is collapsed, skipping your own app's other windows.

The rows budget applies to the visible rows.

What isolated = false changes

Alt+Tab / Shift+Alt+Tab on that workspace lists every non-minimized window across all workspaces in MRU order (sticky windows are naturally included everywhere). Committing a selection parked on another workspace switches to it and focuses it, so the gesture can take you across workspaces, like the stock switcher. Mid-gesture the list is never swapped under a held Alt, and a workspace switch voids the session.

Live apply

The daemon checks the file's modification time each time a gesture starts, so an edit applies on the next Alt+Tab with no restart or re-login. A session keeps the settings it opened with until Alt is released.

Errors and limits

A bad config never breaks switching:

  • Missing or empty file: every workspace isolated, silently.
  • Malformed file: the daemon logs a diagnostic naming the offending line/column or the 1-based entry number, and keeps using the last-good settings (defaults, if none ever parsed). Fixing the file re-applies it.
  • Bad entries: both name and index, neither, index = 0 or negative, or a wrong type (name = 3, isolated = "yes") each name their entry number.
  • [workspace] with single brackets is rejected: entries must be [[workspace]] (an array of tables). One [workspace] table cannot carry several rules anyway.
  • A bad theme value (theme = 3, theme = "blue") is named in a diagnostic; the last-good settings apply.
  • A bad rows value (rows = 8.5, rows = "8", or outside 3–10) is named ("must be a whole number" / "must be between 3 and 10"); the last-good settings apply.
  • A bad font value (font = 12, [font]) is named ("font must be a font family name (a string)"); the last-good settings apply. A family that is not installed is not a config error: the daemon logs the fallback to the interface font.
  • A bad font_size value (font_size = 12.5, font_size = "12", or outside 8–24) is named ("must be a whole number" / "must be between 8 and 24"); the last-good settings apply.
  • A bad layout value (layout = 1, layout = "side") is named; the last-good settings apply.
  • A bad columns value (anything but "auto" or a whole number 3–12) is named; the last-good settings apply.
  • A bad width or min-width value (anything but "auto", a percentage 1–100, or a whole pixel count of 1 or more: "0%", "101%", 0, "640") is named per key; the last-good settings apply. A pixel count past the output is not an error: it clamps to the output with a logged note, and the setting keeps its value.
  • A bad grouping value (grouping = 1, grouping = "yes") is named ("grouping must be a boolean"); the last-good settings apply.
  • Unknown keys are ignored: extra keys inside an entry cost nothing.
  • Size cap: files over 1 MiB are ignored entirely (defaults apply); the read runs on the gesture path and must stay cheap.

Verifying it

  • Edit the config while the daemon runs; the next Alt+Tab reflects it
  • Rename a matched workspace in COSMIC; the entry follows the name on the next press
  • On an isolated = false workspace, Alt+Tab walks every non-minimized window in MRU order, and committing one parked elsewhere switches to it
  • Set theme = "light" on a dark-mode desktop; the next Alt+Tab paints the light card ("dark" paints the dark card on a light-mode desktop). On "auto", flip COSMIC's dark mode and the next press already matches
  • Set rows = 10, then rows = 3; the next Alt+Tab keeps that many windows in view, … rows riding on top, with no restart
  • Set layout = "horizontal"; the next Alt+Tab lays the same windows out as a band of tiles: Left/Right step, the first nine tiles show their Ctrl+N corner badges, a long list ends in a … tile. Set layout = "vertical" and the tall card returns; grouping = true renders the grouped card, vertical whatever layout says
  • With the band open, set columns = 3, then columns = 12; each applies on the next press. On "auto" the band refits when the gesture starts on a different-sized output
  • Set width = "100%"; the next Alt+Tab's card spans the output's logical width, its rows or tiles left-aligned inside it. Set width = 400 on a card that needs more and the card stays as wide as its content, the floor never clipping. A pixel count past the output clamps to it and the daemon log names the clamp
  • Flip COSMIC's Appearance style (Round / Slightly-Round / Square); the next Alt+Tab's corners already match, at 12 / 8 / 2 px
  • Flip COSMIC's interface density (Compact / Comfortable / Spacious); the next Alt+Tab's rows tighten or breathe (40 / 48 / 56 px), and the card's width stays put
  • At Spacious density, set rows = 10; the card opens clamped to eight windows and the daemon log names the clamp; the setting keeps its value
  • Set font = "Fira Sans"; the next Alt+Tab paints it, with no restart. Edit it under held Alt: the open card does not repaint until the next press
  • Set font_size = 16 (or 8, or 24); the next Alt+Tab paints larger or smaller text, the rows and the query strip grow, the title band fits fewer columns instead of stretching wider, and a long title elides sooner. At 24 px on a Spacious desktop the default rows = 8 clamps to six and the daemon log names the clamp
  • Set font_size = 30; the daemon log names the range and the last-good settings apply
  • Unset font: the next Alt+Tab paints the desktop's interface font; flip COSMIC Settings' own font and the next press follows
  • Open a window with a CJK or emoji title: the glyphs render for real
  • Set font = "Not Installed"; the daemon log names the key and the card paints the interface font
  • With grouping = true: expand a group (→), release Alt, press Alt+Tab again; the step continues the walk from where it left off, through the expanded group's windows and on to the next app; Tab and ↓ land on the expanded entry like any row
